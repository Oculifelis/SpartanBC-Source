# Changelog

## 0.3.0

- Works with every Spartan Weaponry port, whichever one is installed: Spartan Weaponry Unofficial, the Vladeezy port, the sanufsoii Fabric port and the original mod on Forge 1.20.1.
- Works with any Better Combat build, Rekindled Combat included.
- One file runs on both NeoForge and Fabric.
- New builds for 1.21.11, 26.1, 26.2 and 26.3.
- Battle hammers swing as hammers.
- Longbows and heavy crossbows use the two-handed bow poses.
- Thrown weapons keep their throw.

## 0.2.0

- Adds a Forge 1.20.1 build for the original Spartan Weaponry by ObliviousSpartan.
- Adds Better Combat attack animations for greatswords, katanas, spears, warhammers and other Spartan melee weapons. Javelins and other thrown weapons keep their throw.
- Adds optional support for weapons from the Ice and Fire addon for Spartan Weaponry.
- Uses the standalone mod ID `spartan_bc`.
